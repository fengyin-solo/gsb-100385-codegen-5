# 田野考古发掘数字化管理系统

面向考古发掘现场探方管理、地层记录、遗迹测绘、遗物登记、浮选采样与测年送检全流程的田野考古数字化管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出、跨模块事务
│   ├── src/api/exchange.ts        出土遗物外业交换封包：导出、校验、幂等导入
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 外业交换封包（出土遗物）

出土遗物模块支持离线交换：在「出土遗物管理」页按器物编号、发掘区（落在「出土探方」字段上检索）、
出土层位、登记状态挑选记录，生成 `AXP-*.json` 封包文件；文件内含记录清单与整包 SHA-256 校验摘要
（`frontend/src/utils/checksum.ts`，纯 TS 实现，浏览器与 node 结果一致）。换一台设备在同一页面
导入封包，即可继续清洗、编号、入库。

- **校验**：导入前核对格式标识、格式版本、记录条数与整包 SHA-256 摘要，任一不符整包拒收，
  本地数据不动。
- **幂等**：按器物编号对账，本地没有才新增；同一封包反复装载，已同步的记录全部判「无变化」，
  不会多出遗物，也不会重复改动。
- **冲突裁决**：每条记录带修订号 `rev`（本地每改一次 +1）与 `updatedAt`。封包 rev 更高 →
  采用封包（现场改过的记录不会被跳过）；本地 rev 更高 → 保留本地；rev 相同且内容一致 → 不动；
  rev 相同但内容不同 → 状态在推进序列（已采集→已清洗→已编号→已入库→借出展示）中更靠后者优先，
  再平手比 `updatedAt`，仍并列保留本地（外来封包不覆盖本机尚未外发的修改）。
  每次裁决都写进导入报告，页面上逐条列出。
- **本机 id 不出封包**：到对端重新分配，避免跨设备撞号。

## 办理入库的跨模块事务

「办理入库」不是普通状态流转：它在一个事务里同时更新出土遗物（状态→已入库、写入存放架位）和
库房架位（当前件数 +1，放满自动转「已满」）。可用空间不单独存储，由「容纳件数 − 当前件数」派生，
与当前件数天然同步变化。事务先把两个模块的改动算在草稿上，任何一步失败（未先编号、无可用架位、
件数不是数值）都整体回滚、两边都不落盘；提交时整库一次性写入 localStorage。
见 `frontend/src/api/local-service.ts` 的 `transact` 与 `warehouseArtifact`。

行为验证：`cd frontend && npm run test:exchange`（用 esbuild 把
`frontend/tests/exchange-verify.mts` 打包后在 node 里跑，覆盖摘要校验、幂等导入、
冲突裁决与入库事务回滚）。

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `field-archaeology-digital:entries` 这一项，或调用 `resetModule(模块)`。
